## ⏱️ 3. Time & Space Complexity -- (completed)

### What is Time Complexity?
It tells **how fast an algorithm grows** as input size increases.

- Big-O notation
- Best / Average / Worst case
- O(1), O(log n), O(n), O(n²), O(2ⁿ)
- Counting operations

### What is Space Complexity?
Extra memory used by an algorithm.

## 🎯 Key Clarification (Very Important)

### What is a Data Structure?
> A way to **store and organize data**  
Examples: Array, Stack, Tree, Graph

### What is NOT a Data Structure?
- Dynamic Programming
- Greedy
- Backtracking

These are **problem-solving techniques**.
